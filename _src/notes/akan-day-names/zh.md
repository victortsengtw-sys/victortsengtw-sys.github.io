在象牙海岸（西非、講法語、全世界最大的可可產地）工作一段時間，你很可能會發現通訊錄裡有好幾位 Kouassi、Koffi 或 Adjoua。這不是巧合：這些名字來自 Akan 人依「出生那天是星期幾」來命名的傳統。了解這套系統，能幫你記住名字，也多一個與人聊天的話題。

## 什麼是 Akan 星期名字

Akan 是分布在迦納、象牙海岸與多哥一帶的族群文化圈。象牙海岸最大的族群之一 Baoulé，以及 Agni（Anyi）等，都屬於 Akan。Baoulé 傳統上居住在象牙海岸中部、Bandama 河與 N'Zi 河之間的地帶，涵蓋布瓦凱（Bouaké）與亞穆蘇克羅一帶；相傳由女王 Abla Pokou 在約 1730 年建立王國。

根據維基百科整理的資料，Akan 傳統會依孩子出生的星期給名字，這個名字也被認為與一個人的靈魂與性格有關。即使許多人另有基督教名或法語名，星期名字依然很普遍，甚至成為常見的姓氏。迦納的寫法如 Kwasi、Kofi、Kwame，在象牙海岸則依法語拼寫習慣變成 Kouassi、Koffi、Kouamé。維基百科也提到，在迦納，大多數人至少有一個這樣的名字。

## Baoulé 星期名字一覽

以下是象牙海岸 Baoulé 人常用的對照，從星期一的 Kouassi 開始：

| 出生星期 | 男性名 | 女性名 |
|---|---|---|
| 星期一 | Kouassi | Akissi |
| 星期二 | Kouadio（Kouadjo） | Adjoua |
| 星期三 | Konan | Amlan（Amenan） |
| 星期四 | Kouakou | Ahou |
| 星期五 | Yao | Aya |
| 星期六 | Koffi | Affoué |
| 星期日 | Kouamé | Amoin |

要注意的是，拼法因家庭與地區而異；迦納 Akan 的常見對照（例如 Kwasi 對應星期日）與上表相差一天，維基百科也提到 Baoulé 的曆法與其他 Akan 群體略有差異。因此，**不要只憑名字斷定某人的生日**，想知道最好直接問。

## 不只看星期：排行名字

除了星期名字，Baoulé 也有依出生排行命名的習慣，有時會取代星期名字。例如第三個孩子可能叫 N'Guessan，第九個叫 N'Goran，第十個叫 Brou，而且不分男女。所以當你看到 N'Guessan 或 Brou 這類名字，它們背後可能也有一段家族故事。

## 在商務往來中的實用意義

- **記名字要連同姓氏與職稱**：同一家公司可能有兩位 Kouassi，寫信、存聯絡人時，記得把全名與職稱一起記下。
- **是很好的破冰話題**：禮貌地問一句「您的名字是不是代表某個星期？」，多半能開啟輕鬆的對話。
- **不要拿名字開玩笑或下定論**：名字與家族、信仰相連，好奇可以，評論要小心。
- **並非所有象牙海岸人都用這套系統**：這是 Akan 文化圈的傳統，其他族群有各自的命名方式。

## 給亞洲讀者的一句話

下次遇到 Koffi，你可以知道他的名字很可能和星期六有關；但最好的做法，是把它當成請教的起點，而不是答案。
